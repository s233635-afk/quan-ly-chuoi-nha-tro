## 🎓 HOW TO USE

### For Existing Forms
```csharp
// Step 1: Import
using quan_ly_chuoi_nha_tro.GUI;

// Step 2: Apply theme to form
BackColor = ModernTheme.Colors.Background;

// Step 3: Style controls
ModernTheme.StylePrimaryButton(myButton);
ModernTheme.StyleTextBox(myTextBox);
ModernTheme.StyleDataGridView(myGrid);

// Step 4: Use modern controls
var card = new ModernStatCard("Title", "Value", "Subtitle", color);
Controls.Add(card);
```

### For New Forms
```csharp
// Follow the pattern in FrmPaymentManagerModern.cs:
// 1. Create header panel (Dock = Top)
// 2. Create toolbar panel (Dock = Top)
// 3. Create filter panel (Dock = Top)
// 4. Create stats panel (Dock = Top)
// 5. Create grid (Dock = Fill)
// 6. Assemble in reverse order
```

### For Common Patterns
```csharp
// Use UIHelper methods
var toast = UIHelper.ShowToast(this, "Saved!", 3000);
var dialog = UIHelper.CreateModernDialog("Title");
var layout = UIHelper.CreateFormLayout(rows: 5);
var search = UIHelper.CreateSearchBox(onFilter);
var button = UIHelper.CreateQuickActionButton("➕", "Add", color);
```
